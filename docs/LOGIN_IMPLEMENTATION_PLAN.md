# 管理端登录实施记录

## 已确认范围

在现有 Vue 3 + TypeScript + Pinia + Vue Router 项目中实现管理端登录入口，接入现有 JWT 双令牌认证，完成会话恢复、角色门禁、工作台外壳和注销。当前不实现注册、找回密码或业务管理页面，不创建测试账号或批量数据。

管理角色为 `STALL_MANAGER`、`RESTAURANT_MANAGER`、`GENERAL_MANAGER`、`SYSTEM_ADMIN`；顾客不得进入管理端。角色和数据范围仍由后端最终授权。

## 设计与安全约定

- 登录页采用橙色品牌、白色表单和深绿运营信息区；窄屏切换单栏，不依赖外部字体或图片。
- Access Token 与 Refresh Token 使用 `sessionStorage`，不使用 `localStorage`；Pinia 只保留资料和界面状态，不保留 JWT 字符串。
- 登录、资料、刷新、注销统一经同源 `/api` 请求 Gateway；开发代理通过 `.env.local` 中的 `VITE_GATEWAY_URL` 配置。
- `GET /api/users/me/profile` 是角色身份事实来源；前端路由角色判断不能代替服务端授权。
- 并发刷新采用 single-flight；Refresh Token 失败后不循环请求；迟到旧 Token 的 401 复用新 Token；注销只有在服务端确认成功后才清除本地会话。
- 不保存密码，不将 Token 放入 URL、日志或 `localStorage`。`sessionStorage` 仍受同源 XSS 风险影响；更高安全需求可后续评估 BFF + HttpOnly Cookie。
