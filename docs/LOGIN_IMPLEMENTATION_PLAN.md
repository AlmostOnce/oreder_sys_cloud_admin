# 管理端登录实施计划

## 已确认范围

使用现有 Vue 3、TypeScript、Pinia、Vue Router 与后端 JWT 双令牌认证。实现中文登录页、图片验证码、身份恢复、单次并发续期、角色门禁、工作台壳与注销。仅管理角色进入，后端保持最终授权；不增加公开注册、找回密码或业务管理页面。

## 设计与安全边界

- 登录页采用橙色品牌、白色表单与深色食堂运营信息面板；不用外部字体和图片，避免加载依赖。
- Access Token 和 Refresh Token 仅存 `sessionStorage`，不使用 localStorage、不保存密码。会话存储仍受 XSS 威胁，生产后续可升级同源 BFF + HttpOnly Cookie；本次不擅自更改后端协议。
- 经同源 `/api` 访问 Gateway；开发代理默认 `http://127.0.0.1:9090`，机器配置置于被忽略的 `.env.local`。
- `GET /api/users/me/profile` 作为身份事实来源，不把前端解码 JWT 当作授权。
- 管理角色：STALL_MANAGER、RESTAURANT_MANAGER、GENERAL_MANAGER、SYSTEM_ADMIN。前端拒绝 CUSTOMER；业务数据范围继续由服务端校验。
- 刷新为 single-flight；迟到的旧 Token 401 复用新 Token，刷新失败不循环重试。会话代次防止退出后的异步请求恢复登录态。
- 注销调用后端撤销双令牌。撤销失败明确提示，不冒充服务端注销成功。
